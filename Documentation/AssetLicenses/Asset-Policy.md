# Asset Policy

The initial slice uses Unity built-in primitive meshes, Unity's default render pipeline, and code-generated UI only. No third-party assets or paid packages are included. The Unity Editor and Unity packages are project tooling, not redistributed game art. Package versions and provenance are recorded in `Packages/manifest.json` and the architecture docs.

Before adding external content, record the asset name, author, direct source, exact license, commercial-use permissions, attribution needs, platform restrictions, and license check date. Free download does not imply permission for commercial redistribution. Prefer original procedural placeholders until rights are clear.
